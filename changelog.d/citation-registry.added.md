Added `icelake.citations`: a reply-side citation system built on a closed source set with deny-by-default rendering, mirroring how production assistants (ChatGPT, Claude, Perplexity) keep citations reliable. `CitationRegistry` seeds from `PromptContext`, registers link sources (`add_source`) and Discord messages (`add_message`) with library-minted `[src:N]` refs, exposes the model-facing `prompt_contract` / `source_list`, and renders with one call — `apply(text)` splices provider-anchored offsets, weaves echoed refs into Discord-safe links, canonicalizes mangled-but-known references, and deletes every citation-shaped token outside the set (invented `[5]`, unknown `[mem:99]`, self-written `[1](url)` links, `【…】` artifacts). Also added `sources_footer()`, `render_fact_list()`, and top-level exports of `CitationRegistry`, `CitationSource`, `message_url`, and `render_fact_list`.
