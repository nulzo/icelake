`PromptContext.apply_citations` now delegates to `CitationRegistry.apply` — a single rendering implementation for all citation handling. Behavior tightens deny-by-default: bare invented numbers (`prefers algebra [5]`), model-written `[N](url)` links whose target is not a registered source, and `【…】` artifacts are now removed, while word-attached prose like `array[0]` is preserved.
